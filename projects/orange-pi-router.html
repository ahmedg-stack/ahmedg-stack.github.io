Orange Pi Router

A custom network router on an Orange Pi single-board computer. Research stage: nothing has been built or tested yet.

Repo

Goals

  • Route between a WAN port and a LAN port using two Ethernet interfaces.
  • Run NAT, DHCP, DNS, and a firewall myself.
  • Learn Linux networking on real hardware.

Planned architecture

Internet (modem) ──WAN──▶ [ Orange Pi ] ──LAN──▶ switch / devices
                           ├─ routing + NAT
                           ├─ DHCP
                           ├─ DNS
                           └─ firewall

Roadmap

  • ✅ Research hardware, dual-Ethernet options, and operating systems
  • ⬜ Choose board and second Ethernet interface
  • ⬜ Install OS; bring up WAN and LAN
  • ⬜ Routing, NAT, DHCP, DNS, firewall
  • ⬜ Throughput and latency testing
